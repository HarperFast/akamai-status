# @harperdb/akamai-status - Test Results

## Component Overview

This component provides three endpoints for Akamai services:
- `GET /status` - Health check (HTTP 200 when Available, 404 otherwise)
- `GET /current_load_for_gtm` - Load feedback for Akamai GTM (format: `load:N`)
- `GET /akamai/sureroute-test-object.html` - Static HTML for SureRoute testing

## Test Environment

**Cluster:** v5-testing.akamai.stage (HarperFabric)
**Harper Version:** 5.0.0
**Nodes:** nl-ams-1, se-sto-1, us-lax-1, us-ord-1
**Instance Type:** 1 CPU, 2 HTTP threads, 4GB memory

## 2. Load Endpoint - Configuration

**Node tested:** nl-ams-1

### TEST 2.1: Default Configuration

**Config:** None (defaults: scale=1000, max=1000)
**Formula:** `utilization × 1000`

```bash
curl -sk https://nl-ams-1.v5-testing.akamai.stage.harperfabric.com/current_load_for_gtm
# "load:713"

curl -sk https://nl-ams-1.v5-testing.akamai.stage.harperfabric.com/debug_load
# {"nodeName":"iuk-nl-ams-1...","utilization":0.7133864339918877}
```

`0.7134 × 1000 = 713` ✓ **PASS**

### TEST 2.2: Custom Scale (100)

**Config:**
```yaml
akamaiStatus:
  loadThresholds:
    scale: 100
```

**Formula:** `utilization × 100`

```bash
curl -sk https://nl-ams-1.v5-testing.akamai.stage.harperfabric.com/current_load_for_gtm
# "load:71"

curl -sk https://nl-ams-1.v5-testing.akamai.stage.harperfabric.com/debug_load
# {"nodeName":"iuk-nl-ams-1...","utilization":0.7147890215900389}
```

`0.7148 × 100 = 71` ✓ **PASS**

### TEST 2.3: Custom Max (500)

**Config:**
```yaml
akamaiStatus:
  loadThresholds:
    scale: 1000
    max: 500
```

**Formula:** `min(utilization × 1000, 500)`

```bash
curl -sk https://nl-ams-1.v5-testing.akamai.stage.harperfabric.com/current_load_for_gtm
# "load:500"

curl -sk https://nl-ams-1.v5-testing.akamai.stage.harperfabric.com/debug_load
# {"nodeName":"iuk-nl-ams-1...","utilization":0.7145650359610981}
```

`0.7146 × 1000 = 714`, capped at 500 ✓ **PASS**

## 3. Load Endpoint - Per-Node Reporting

**Cluster:** All 4 nodes, analytics.replicate: true

Each node in a replicated cluster reports only its own utilization.

Four different node names, four different utilization values. **PASS**

### TEST 3.2: Load Differs Under Targeted Stress

| se-sto-1 | 705 |
| **us-lax-1** | **877** ← stressed |
| us-ord-1 | 694 |

Only the stressed node reports elevated load. **PASS**

## 4. Akamai GTM Integration

**GTM Domain:** loadbalance-test.akadns.net
**GTM Property:** akamai-status-test (Weighted Random Load Balancing with Load Feedback)

### GTM Configuration

| Setting | Value |
|---|---|
| Property Type | Weighted Random Load Balancing with Load Feedback |
| Resource Name | load |
| Resource Type | Non-XML load object via HTTP |
| Load Leader String | `load:` |
| Upper Bound | 1000 |
| Load Object | `/current_load_for_gtm` (port 443, per datacenter) |
| Liveness Test | HTTPS GET `/status`, response string: "reporting for duty" |

### TEST 4.1: DNS Resolution Through GTM

```bash
$ dig akamai-status-test.loadbalance-test.akadns.net

akamai-status-test.loadbalance-test.akadns.net. 60 IN CNAME se-sto-1.v5-testing.akamai.stage.harperfabric.com.
se-sto-1.v5-testing.akamai.stage.harperfabric.com. 300 IN A 172.232.139.197
```

GTM resolves to the geographically closest node. **PASS**
